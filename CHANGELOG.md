# Changelog

## 1.0.0 — 2026-10-04

- Initial public release of Opulent Hardware Module Runtime.
- Added local Windows master and per-application audio controls.
- Added playback-device and microphone management.
- Added now-playing metadata, artwork, progress, transport, and supported seeking.
- Added capability discovery and widget handshake endpoints.
- Enabled Start with Windows by default on first launch while preserving later user opt-out.
- Restricted the service to loopback with local-origin checks and Private Network Access support.
